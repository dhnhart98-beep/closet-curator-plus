# Closet Curator+

An iPad-friendly wardrobe curation progressive web app prototype.

## Included
- Clothing and accessory photo uploads
- Camera/photo-library support on iPad
- Categories, seasons, occasions, brand, price, notes, and wear count
- Search, filters, favorites, and closet insights
- Outfit generator and saved lookbook
- Weather/occasion/mood styling rules
- Weekly outfit planner
- Vacation packing assistant
- Wardrobe-gap recommendations
- Personal shopping list
- Cost-per-wear analytics
- Beauty, fragrance, handbag, and accessory organization
- Backup export/import
- Progressive web app structure for Home Screen installation
- Offline caching after first load

## Open on iPad
1. Unzip the folder in Files.
2. Host the folder using a simple static website host, or open index.html with an HTML viewer.
3. In Safari, use Share > Add to Home Screen.

## Production features that require services
The interface is prepared for these, but they require paid or configured external services:
- Real AI image recognition and automatic tagging
- Background removal
- Live weather
- Account authentication
- iCloud or cross-device cloud photo sync
- App Store distribution
